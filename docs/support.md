# bleeply Support

Get help from Artem Tabenskii through [GitHub Issues](https://github.com/IceRedline/bleeply/issues). A GitHub account is needed to open an issue. Reports are public; never attach private recordings, transcripts or personal information.

## Reporting a problem

Include the app version and build from About bleeply, your macOS version, your Mac model, the selected recognition engine and model, and the steps that caused the problem. Copy the error message if one is shown. A description is usually enough; recordings are not required.

## First run and model downloads

Choose the language and open an audio or video file. The first use of an uncached model asks for download permission and shows its estimated download size. Models are retained for offline use. Settings shows the size of each selected model, including required alignment models. Leave extra disk space for temporary files and exports.

If downloads are disabled, enable “Allow first-time model download” in Settings and reopen the file. Interrupted downloads can be retried. Recognition requires an Apple Silicon Mac running macOS 15 or later.

## Reviewing and exporting

Automatic recognition can miss words. Use Advanced mode to review the transcript and censor intervals before exporting. Existing reviewed mute intervals are preserved; the selected censor sound plays once at its original speed. The original recording is not overwritten.

If an export destination already exists, choose a new filename. If a saved review's source has moved, open the media file again to grant access.

## Privacy

Recordings are processed locally. Open Privacy Policy from Settings or the Help menu for details about downloads, local storage, deletion and optional feedback.
