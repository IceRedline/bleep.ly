# bleeply 0.1.3

A packaging reliability update for **Apple Silicon Macs running macOS 15.0 or later**.

- Fixes permissions in both bundled Python runtimes so every user can read the app’s files and macOS can verify its signature after installation. Packaging now checks the permissions recorded inside the installer and the mounted DMG.
- Adds a separate App Sandbox build for TestFlight, including access to selected media, saved review bookmarks, and cancellable exports.
- Includes the latest model-download consent changes: missing models prompt for permission, approved downloads continue processing automatically, and cached models work offline.
- Preserves approved mute boundaries and full custom-sound playback. Speech resumes on its original schedule.

## Installation

Open `bleeply-0.1.3-arm64.dmg` and drag the app to **Applications**, replacing the previous version. The app and DMG are signed with Developer ID and notarized by Apple. Python, FFmpeg, and recognition engines are included; models download separately. Recordings stay on your Mac.

The direct-download and TestFlight variants are version **0.1.3**, build **12**.

Files: `bleeply-0.1.3-arm64.dmg`, `SHA256SUMS`, and `ffmpeg-8.1.2.tar.xz` (LGPL source archive).

This is a historical release. Its signed installer retains the application name used when it was built; the current project name is **bleeply**.
