# bleeply 0.1.8

Privacy information, clearer model download sizes, and updated open source packaging for **Apple Silicon Macs running macOS 15.0 or later**.

- **Privacy Policy available offline.** Read how bleeply handles recordings, model downloads and optional feedback from Settings or the Help menu, even without an internet connection.
- **Support and license information inside the app.** Open the GitHub support page and browse open source notices from Settings and Help.
- **Know the download size before you start.** The permission prompt and Settings show the selected model's estimated full download size, including required alignment models. Estimates may differ from the remaining download when files are already cached.
- **Updated PyAV and FFmpeg packaging.** Both embedded Python runtimes now use PyAV built against LGPL-only FFmpeg, without x264/x265. The app includes the exact FFmpeg and PyAV source archives, licenses, build configuration and rebuild instructions under Open Source Licenses. Packaging checks reject incompatible codec libraries and mismatched source archives.

Recognition, alignment and export continue to run locally. Model downloads require permission. Updating retains settings, downloaded models and saved reviews.

## Installation

Quit the previous app, open `bleeply-0.1.8-arm64.dmg`, and drag the app to **Applications**, replacing the previous version. The app and DMG are signed with Developer ID and notarized by Apple. Python, FFmpeg and recognition engines are included; models download separately.

Direct download: version **0.1.8**, build **18**. This release does not upload or submit a TestFlight build. The separately prepared 0.1.7 (17) TestFlight candidate is preserved.

Release assets:

- `bleeply-0.1.8-arm64.dmg` — signed and notarized installer.
- `ffmpeg-8.1.2.tar.xz` — corresponding FFmpeg source archive.
- `av-18.1.0.tar.gz` — corresponding PyAV source archive.
- `SHA256SUMS` — SHA-256 checksums for all three files.

To verify the downloaded files, place them in the same directory and run `shasum -a 256 -c SHA256SUMS`.
