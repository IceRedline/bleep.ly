# bleeply 0.1.9

The first installer under the **bleeply** name, with recognition and preview fixes for **Apple Silicon Macs running macOS 15.0 or later**.

- **A consistent new name.** The app, installer, command-line output, Final Cut events, documentation and support links now use bleeply.
- **Keep your saved work.** On first launch, the app moves the previous Application Support folder to `~/Library/Application Support/bleeply/`, retaining downloaded models, reviews, bookmarks and custom sounds. Existing files in the new location take precedence. The bundle identifier stays unchanged to preserve preferences and signing compatibility.
- **Explicit CPU recognition.** CPU mode is supported across the available Apple Silicon recognition models, including their alignment stages. Recognition history records the requested device policy.
- **Ogg playback.** Preview Opus and Vorbis audio through decoded audio when native playback cannot open the source codec.
- **Clearer export completion and errors.** Completed exports show their follow-up actions, and failures include worker or native diagnostic codes.
- **Reproducible developer benchmarks.** The source includes Turbo audio speed tests for comparing Macs, with explicit compute policies and a recorded M3 Pro reference run.

Recognition, alignment and export run locally. Models download only after permission. Approved mute boundaries and complete custom-sound playback remain unchanged.

## Installation

Quit the previous app, open `bleeply-0.1.9-arm64.dmg`, and drag **bleeply** to **Applications**. Replace an existing bleeply app if prompted. If your previous version uses a different app name, remove that old app after launching the update successfully; keep its Application Support folder so the update can migrate your data. Avoid running the old and new apps at the same time.

The app and DMG are signed with Developer ID and notarized by Apple. Python, FFmpeg and recognition engines are included; models download separately.

Direct download: version **0.1.9**, build **19**. This release does not upload or submit a TestFlight build.

Release assets:

- `bleeply-0.1.9-arm64.dmg` — signed and notarized installer.
- `ffmpeg-8.1.2.tar.xz` — corresponding FFmpeg source archive.
- `av-18.1.0.tar.gz` — corresponding PyAV source archive.
- `SHA256SUMS` — SHA-256 checksums for all three files.

To verify the downloaded files, place them in the same directory and run `shasum -a 256 -c SHA256SUMS`.
