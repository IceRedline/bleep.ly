# bleep.ly 0.1.1

This compatibility update supports **Apple Silicon Macs (M1 or later) running macOS 15.0 Sequoia or later**.

MLX remains at version 0.32.3. Both bundled Python runtimes now include the official macOS 15 packages instead of the macOS 26.2 packages. Model versions and censoring rules are unchanged.

- The bundler checks the minimum macOS version of every native library and rejects builds that require a version newer than 15.0.
- CI checks both complete recognition runtimes on macOS 15, along with all Python and Swift application tests.
- To update from 0.1.0, open the DMG and drag **bleep.ly** to **Applications**, replacing the previous version. Downloaded models, settings, and drafts are preserved.

Python, FFmpeg, and recognition engines are included. Models download separately when **Allow first-time model download** is enabled. The app and DMG are signed with Developer ID and notarized by Apple.

Files: `bleep.ly-0.1.1-arm64.dmg`, `SHA256SUMS`, and the `ffmpeg-8.1.2.tar.xz` source archive (LGPL).
