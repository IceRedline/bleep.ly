# bleep.ly 0.1.1

Исправлена совместимость установочной сборки: теперь требуется **macOS 15.0 Sequoia или новее**, Mac с **Apple Silicon** (M1 и новее).

Версия MLX осталась 0.32.3. В оба встроенных Python-окружения включены официальные пакеты для macOS 15 вместо пакетов для 26.2. Версии моделей и правила цензуры не менялись.

- Упаковщик проверяет минимальную версию macOS у каждой нативной библиотеки и запрещает собирать релиз с требованиями выше 15.0.
- CI проверяет оба полных окружения распознавания на macOS 15, вместе со всеми Python- и Swift-тестами приложения.
- Установите новую версию поверх 0.1.0: откройте DMG и перенесите **bleep.ly** в **Applications** с заменой. Сохранённые модели, настройки и черновики сохраняются.

Python, FFmpeg и движки распознавания включены в приложение. Модели скачиваются отдельно при включённом **Allow first-time model download**. Приложение и DMG подписаны Developer ID и нотариализованы Apple.

Файлы: `bleep.ly-0.1.1-arm64.dmg`, `SHA256SUMS`, исходный архив `ffmpeg-8.1.2.tar.xz` (LGPL).

**English:** Compatibility fix for Apple Silicon Macs running macOS 15.0 Sequoia or later. Uses the official macOS 15 builds of MLX 0.32.3 in both bundled runtimes. Install over 0.1.0; existing settings, models and reviews are preserved. Signed and notarized; Python, FFmpeg and recognition engines are included.
