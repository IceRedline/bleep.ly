# bleeply 0.1.10

Recognition defaults and more reliable GigaAM word timing for **Apple Silicon Macs running macOS 15.0 or later**.

- **Consistent first launch.** New installations start in English with Whisper Large v3 Turbo on CPU. Switching to Russian selects GigaAM v3; switching back to English selects Whisper Turbo. Existing saved preferences are preserved.
- **More reliable Russian word timing.** Qwen alignment now rejects intervals detached from GigaAM's original word timing. If a bounded retry is still implausible, the app retains the original interval. This fixes the reported final word being marked roughly half a second early. The alignment cache version has changed so new analyses recompute affected results.
- **M3 benchmark results.** Added the original M3 8 GiB reports and updated benchmark tables. Median Turbo recognition times across three repeats: CPU **206.46 s**, GPU **111.32 s**, CPU + Neural Engine **50.06 s**. The first observed run is excluded; all successful repeats are retained.

This release retains the corrected app icon, native dependency packaging and dependency notices from 0.1.9 build 23. Recognition and export run locally. Approved mute boundaries and complete custom-sound playback are preserved.

To reanalyze a file with the timing fix, open the original recording again. Resuming a saved review preserves its existing word timings and manual edits.

## Installation

Quit bleeply, open `bleeply-0.1.10-arm64.dmg`, and drag **bleeply** to **Applications**, replacing the previous app. Settings, downloaded models and saved reviews are retained.

The app and DMG are signed with Developer ID and notarized by Apple. Python, FFmpeg and recognition engines are included; models download separately.

Direct download: version **0.1.10**, build **24**. This GitHub release does not upload a TestFlight build or submit App Review.
