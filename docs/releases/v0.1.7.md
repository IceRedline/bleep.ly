# bleeply 0.1.7

Clearer model downloads and a more consistent interface on **Apple Silicon Macs running macOS 15.0 or later**.

- **See real model download progress.** Qwen, GigaAM, Parakeet and Whisper downloads show received bytes out of the total when the size is available. Qwen downloads update as data arrives instead of jumping from a small amount straight to completion. Unknown-size transfers show downloaded bytes with an indeterminate bar.
- **Exactly one loading indicator.** Model downloads use a linear bar. Recognition, export, model checks and other processing stages use the circular indicator, which animates while progress is unknown. No stage is left without an indicator.
- **Clearer preparation stages.** Named checking, downloading and loading steps replace the generic experimental-model message. Model preparation and downloads no longer show elapsed time or estimated time remaining; recognition and export keep their timing metrics.
- **A steadier processing screen.** A compact area switches between preparation explanations, downloaded bytes and processing metrics while Cancel stays in place. The privacy note sits below Cancel.
- **Consistent mint accents.** The censor sound selector, Settings, editors and native controls use the app's mint accent, with light and dark appearance support.
- **Readable controls when macOS uses Light appearance.** Keep native controls on the dark main canvas in Dark appearance, preventing black language-picker text on the dark background. Settings still follow the system appearance.
- **Fix first-run preparation errors.** Resolve the `TextIOWrapper is not JSON serializable` failure in the desktop worker and cover model-download permission on a clean start in the packaged-app smoke checks.

Recognition, alignment and export run locally. Model downloads still require permission; existing downloaded models are retained when updating.

## Installation

Open `bleeply-0.1.7-arm64.dmg` and drag the app to **Applications**, replacing the previous version. Quit the previous app before opening the update. The app and DMG are signed with Developer ID and notarized by Apple. Python, FFmpeg and recognition engines are included; models download separately. Recordings stay on your Mac.

Direct download: version **0.1.7**, build **16**. This release does not publish a new TestFlight build.

Files: `bleeply-0.1.7-arm64.dmg`, `SHA256SUMS`, and `ffmpeg-8.1.2.tar.xz` (LGPL source archive).

This is a historical release. Its signed installer retains the application name used when it was built; the current project name is **bleeply**.
